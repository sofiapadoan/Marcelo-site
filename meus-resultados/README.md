# Meus resultados odontológicos

Esta pasta receberá resultados odontológicos reais fornecidos para o projeto.

## Regras de uso

- Preservar os arquivos originais recebidos.
- Não atribuir procedimento, profissional, prazo ou resultado sem informação confirmada.
- Registrar contexto e legenda aprovados para cada caso antes de publicar.
- Confirmar autorização de uso de imagem e consentimento aplicável a todos os pacientes identificáveis.
- Não prometer que outras pessoas obterão resultados iguais.
- Não confundir estes arquivos com imagens meramente ilustrativas de `../imagens-site`.
