# Imagens de exemplo para o site

Esta pasta receberá imagens de exemplo organizadas por procedimento, fornecidas posteriormente.

Os prompts padronizados da primeira coleção estão em `prompts-tratamentos.md`.

## Imagens aprovadas por tratamento

- Implantes: `implantes.png`.
- Prótese dentária: `protese-dentaria.png`.
- Estética dental: `estetica-dental.png`.
- Clareamento dental: `clareamento-dental.png`.
- Ortodontia: `ortodontia.png`.
- Odontopediatria: `odontopediatria.png`.

Essas imagens são ilustrativas e devem ser usadas somente no card ou conteúdo do tratamento correspondente. Não apresentá-las como casos, pacientes ou resultados reais da clínica.

## Regras de uso

- Preservar os arquivos originais recebidos.
- Identificar claramente quando uma imagem for ilustrativa.
- Não apresentar imagem de exemplo como resultado obtido pela Clínica Renova Odontologia.
- Confirmar licença, autoria e autorização de uso antes da publicação.
- Não inferir tratamentos oferecidos apenas pela presença de uma imagem nesta pasta; cada serviço precisa de confirmação explícita.
- Não misturar estes arquivos com resultados reais de `../meus-resultados`.
